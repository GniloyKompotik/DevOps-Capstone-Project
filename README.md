# DevOps Capstone Project

[![Build Status](https://github.com/christian-schw/devops-capstone-project/workflows/CI%20Build/badge.svg)](https://github.com/christian-schw/devops-capstone-project/actions)

## Overview
This repository contains the RESTful Customer Accounts microservice built with Python Flask, SQLAlchemy, Docker, and Kubernetes for the IBM DevOps Capstone course.

## Features
- Full RESTful CRUD operations for Customer Accounts.
- Security Headers configured via Flask-Talisman and CORS support.
- Automated CI/CD pipelines with GitHub Actions and Tekton.
- Containerized with Docker and deployed to Kubernetes.
